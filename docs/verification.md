## Limits of the present audit

- This update corrects documented identity/link errors and checks the added records; it is not a full-text security, protocol, or reproducibility audit of every paper.
- `inherited` records have not all been re-verified. `crossref-2026-10-12` records had publisher-deposited metadata checked; `checked-2026-10-12` records were individually reconciled with the sources recorded in the catalogue or update notes.
- The A/A* and Q1 preference is not a blanket certification of all retained venues. Ranking edition, subject category, and publication year should be supplied before using this list as a strict eligibility filter.
- Code repositories retained from the earlier list have not all been audited for authorship, license, or reproducibility.
- Thematic placement is editorial interpretation. In particular, the shared-artifact security subsection identifies an exposure surface, not a demonstrated attack or defense.
- Do not compare reported accuracies without matching held-out domains, client-domain mappings, backbone pretraining, public data, and target-access rules.
